# v0.6.0 — Distribution and reach

Released **14 November 2026**.

## Summary

v0.6.0 widens where bookings come from and how prices are shown. It ships the
channel manager (iCal import/export), a multi-currency display and a mobile PWA
install prompt. The guest journey from v0.5.0 is unchanged; these additions
sit on top of it.

## Channel manager

- `ChannelFeed` is per physical room and stores `url`, `last_synced_at`,
  `last_error`, `last_event_count` and `conflict_count`.
- `RoomBlock` stores `room`, nullable `feed`, `check_in`, `check_out`, `source`
  (`channel` / `manual`), `external_uid` and `summary`, with a conditional
  unique constraint on `(feed, external_uid)`.
- OTA reservations are imported into `RoomBlock` rows, never synthetic
  `Booking` rows, so availability, creation and modification honour them without
  touching the booking write path.
- `sync_feed()` unfolds folded iCal lines and parses `DATE` and `DATE-TIME`
  values (Z and naive/TZID), skips `STATUS:CANCELLED`, upserts by
  `(feed, external_uid)`, removes stale events and preserves existing blocks on
  fetch failure. Conflicts with local blocking bookings are counted.
- `sync_all_feeds()` and the `sync_channel_feeds` management command (dry-run
  by default, `--apply` to write) drive the loop; the scheduler sidecar runs
  `sync_channel_feeds --apply`.
- `booked_room_ids()` unions overlapping `RoomBlock` room ids; `Booking.clean()`
  rejects a booking that overlaps a block.
- The hotel's availability is exported at `/calendar/<token>.ics` using a
  signed token (`django.core.signing`, salt `hotel.channel_feed`); pending
  holds are `TENTATIVE`, confirmed bookings `CONFIRMED`, plus manual and
  channel blocks.
- Reception can add manual blocks in the admin; `/ops/` shows feed errors,
  conflicts, a feed table and upcoming blocks.

## Multi-currency display

- A currency selector in the header sets a session cookie; prices render with
  an indicative conversion next to the base-currency total through the `money`
  template filter.
- Stored amounts always stay in the hotel currency; rates come from
  `HOTEL["exchange_rates"]` (env `EXCHANGE_RATES`) and supported currencies
  from `SUPPORTED_DISPLAY_CURRENCIES`.

## Mobile PWA

- `manifest.json`, a service worker caching static assets and visited pages, and
  an install button shown on `beforeinstallprompt`.
- The booking page stays renderable when the network drops, using cached pages.

## Upgrade notes

1. Run `manage.py migrate`. Migration `0011_channelfeed_roomblock` is required.
2. New optional environment variables: `CHANNEL_FEED_TIMEOUT_SECONDS` (10),
   `SUPPORTED_DISPLAY_CURRENCIES`, `EXCHANGE_RATES`.
3. On a host without Docker, add `sync_channel_feeds --apply` to the scheduler.
