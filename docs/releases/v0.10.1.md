# v0.10.1 - Branding and UI polish

**Released:** 2026-11-21

## Summary

Patch release refreshing the product branding to Hotel Aurora and applying a Hilton-inspired blue design system across the guest frontend and Django admin. The voice concierge gets a redesigned call box and a modern orb animation while keeping the existing voice behavior and JS contract intact.

## Changes

- **Hotel Aurora branding refresh**
  - Updated hotel/product naming and defaults from Resort Neptun to Hotel Aurora across settings, env templates, docs, scripts, manifest, and tests.
  - Regenerated Polish translations after branding/script updates.

- **Hilton-inspired frontend styling**
  - Replaced the warm green/cream palette with a blue-dominant design system (navy/blue primaries, cool neutrals, restrained gold accent) while preserving existing CSS token names for compatibility.
  - Updated components, gradients, shadows, and leftover hardcoded palette remnants to the new theme.

- **Django admin styling**
  - Added `templates/admin/base_site.html` and `static/css/admin.css` for a Hilton-inspired admin theme: branded header, blue breadcrumbs/modules/buttons/object tools, and light/dark theme variable overrides compatible with Django admin theme toggling.

- **Voice concierge polish**
  - Redesigned the voice call card with a premium blue treatment and improved call button/status styling.
  - Replaced the old SVG face avatar with a modern orb/wave visualization (`#voice-avatar` container and JS class contract preserved), with state animations for active/listening/thinking/speaking/pulse and `prefers-reduced-motion` fallback.

- **Accessibility and quality**
  - Updated `tests/test_accessibility.py` token contrast expectations for the new palette, including inverse focus-ring checks on dark surfaces.
  - WCAG AA text/non-text contrast token checks remain green.
